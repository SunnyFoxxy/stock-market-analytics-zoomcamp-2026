# Module 1 Homework — Financial Data Analysis

Homework for the Stock Markets Analytics course (2026 cohort), focused on sourcing and analyzing financial data using Python.

## What's inside
- **Q1:** Scraped S&P 500 constituent data from Wikipedia to find yearly index addition trends and long-tenured constituents.
- **Q2:** Compared YTD and multi-year returns of 10 global stock indexes against the S&P 500.
- **Q3:** Identified and analyzed all S&P 500 market corrections (≥5% drawdowns) since 1950, computing median depth and duration.
- **Q4:** Analyzed Amazon's (AMZN) stock price reaction to earnings surprises, including a bull vs. bear market comparison.

## Tools
Python, pandas, yfinance, requests

## Capstone idea (Q5)
A follow-up project exploring how Brexit reshaped UK market behavior (FTSE 100), compared to the US (S&P 500), through market corrections and earnings-surprise reactions.
